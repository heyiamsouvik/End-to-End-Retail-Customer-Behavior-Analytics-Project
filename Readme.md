# InsightCart 📊

An end-to-end retail customer behavior analytics project built using **Python, SQL, and Power BI** to transform raw shopping data into actionable business insights.

## Project Overview
This project simulates a real-world **Data Analyst workflow** by analyzing retail customer behavior and shopping trends from raw data to business reporting.

The workflow includes:
- Data cleaning and transformation with **Python (Pandas)**
- Exploratory Data Analysis (EDA)
- Business problem solving using **SQL**
- Interactive dashboard creation with **Power BI**
- Business reporting and presentation
- Portfolio publishing on **GitHub**

## Tech Stack
- **Python** – Data cleaning & EDA
- **SQL** – Business analysis
- **Power BI** – Dashboard & visualization
- **GitHub** – Project documentation & portfolio

## Key Insights
- Customer purchasing behavior analysis
- Revenue and sales trend analysis
- Customer segmentation insights
- Product/category performance tracking
- Business recommendations through dashboard storytelling

## Repository Structure
```text
data/          Raw & cleaned datasets
notebooks/     Python analysis notebooks
sql/           SQL queries & analysis
powerbi/       Dashboard files
reports/       Project report & presentation
images/        Dashboard screenshots
```

## Project Goal
To demonstrate a **company-level end-to-end data analytics project** covering data cleaning, analysis, visualization, and business reporting for portfolio and resume use.
